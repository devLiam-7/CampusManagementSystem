# Smart Campus Management System

A Java Swing desktop application for managing campus operations.

## Features
- Role-based login (Admin & Faculty)
- Student Management (Add, Edit, Delete, View)
- Fee Management with auto-calculation
- Timetable Management
- Attendance Tracking
- Critical Students Report with color coding
- Dashboard with real-time stats and charts
- Change Password

## Tech Stack
- Java Swing (UI)
- MySQL (Database)
- JDBC (DB Connection)
- JFreeChart (Charts)
